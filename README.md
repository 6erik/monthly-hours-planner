# Monthly Hours Planner

A simple monthly work-hours planner that runs entirely in the browser. It has no server, build step, or third-party runtime dependencies; GitHub Pages can host it as a static site.

## Run locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the branch and `/ (root)`, then save.

The planner saves its current month and progress in the browser's local storage. That data stays in the browser and is not synced between devices.
